# Security Policy

## Supported Versions

Security fixes are applied to the latest code on `main`. Older releases and other
branches do not receive dedicated security updates.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately. Do not include security-sensitive
details in public issues, pull requests, or discussions.

Use GitHub's **Report a vulnerability** option on the repository's
[Security tab](https://github.com/rit-sse/WebsiteTheSSEquel/security) if it is
available. Otherwise, email
[societyofsoftwareengineers@gmail.com](mailto:societyofsoftwareengineers@gmail.com)
with the subject `WebsiteTheSSEquel security report` and ask for the report to be
forwarded to the website maintainers.

Include the following where possible:

- A description of the issue and its potential impact.
- The affected URL, feature, or code version.
- Steps to reproduce the issue, with a minimal proof of concept if helpful.
- A way to contact you for follow-up questions.

Remove passwords, tokens, personal information, and other sensitive data from any
screenshots, logs, or examples you send.

## Responsible Testing and Disclosure

Use accounts and data you control when investigating an issue. Avoid disrupting
the website, accessing other users' data, or changing or deleting data that is
not yours. If you encounter sensitive information, stop testing and report what
you found without collecting additional data.

Please coordinate public disclosure with the maintainers so they have time to
investigate and address the issue. Response and resolution times depend on
maintainer availability and the severity of the report.
